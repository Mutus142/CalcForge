
# 🧮 CalcForge

![Python](https://img.shields.io/badge/Python-3.x-blue?logo=python&logoColor=white)
![Status](https://img.shields.io/badge/Status-Em%20desenvolvimento-yellow)
![Versão](https://img.shields.io/badge/Vers%C3%A3o-1.0-green)

**CalcForge** é uma calculadora desenvolvida em Python, com interface de terminal, operações matemáticas e tratamento de erros.

O projeto foi criado como um desafio prático após a conclusão de um curso de Python, com o objetivo de aplicar os conhecimentos adquiridos e desenvolver uma aplicação de forma independente.

---

## 🚀 Funcionalidades

- ➕ Adição
- ➖ Subtração
- ➗ Divisão
- ✖️ Multiplicação
- 🔢 Potenciação (quadrado de um número)
- 🛡️ Tratamento de entradas inválidas
- 🚫 Proteção contra divisão por zero
- 🔄 Menus interativos com opção de retorno

**Em desenvolvimento:** histórico de operações matemáticas.

## 🛠️ Tecnologias utilizadas

- **Python:** desenvolvimento da aplicação.
- **Git:** controle de versão.
- **GitHub:** hospedagem do repositório.

## 📂 Estrutura do projeto

```text
CalcForge/
│
├── menu.py
├── calculadora.py
├── historico.py
├── .gitignore
└── README.md
```

O arquivo `menu.py` contém o menu principal da aplicação, enquanto `calculadora.py` reúne as operações matemáticas. O módulo `historico.py` está reservado para futuras atualizações.

## 💻 Como executar

**1. Clone o repositório:**

```bash
git clone https://github.com/Mutus142/CalcForge.git
```

**2. Acesse a pasta:**

```bash
cd CalcForge
```

**3. Execute o programa:**

```bash
python menu.py
```

> Requer Python instalado. A opção de histórico depende da implementação do módulo `historico.py`.
